# Jarned-V2
An improvement on the Jarned V1. A whole spilt keyboard with bluetooth!
I made it as a way to challenge myself after V1!

# Features
- 2 XIAO microcontrollers to control both sides
- 40 Keys!
- Bluetooth connectivity
- An open concept case to be able to marvel at the raw PCB
- 40 Diodes
- ZMK firmware to connect the two
